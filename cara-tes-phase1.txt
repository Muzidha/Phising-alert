### Langkah 2: Cara Menjalankan Ekstensi & Pengujian

Follow langkah-langkah mudah berikut di browser Google Chrome / Brave / Edge kamu:

#### 1. Load Ekstensi ke Browser
1. Buka browser Chrome dan ketik URL: `chrome://extensions/`
2. Aktifkan **Developer mode** di pojok kanan atas (saklar toggle).
3. Klik tombol **Load unpacked** (di kiri atas).
4. Pilih folder project ini: `/home/archer/Projects/phising-project-blocker`
5. Pastikan ekstensi **PhishShield - Phishing Blocker (v1.1.0)** muncul dan aktif.

---

1. Buka tab baru di browser.
2. Buka file [test-page.html](file:///home/archer/Projects/phising-project-blocker/test-page.html) dengan menekan `Ctrl + O` di browser, lalu pilih file `test-page.html` tersebut.

#### 3. Tes Skenario Pengujian

##### 🧪 Tes 1: Form Submit (Pencegatan Form HTML)
1. Di halaman pengujian, klik tombol **"Kirim Data Form"**.
2. **Hasil yang Diharapkan:**
   - Ekstensi akan menahan pengiriman form.
   - **Modal Transparency Alert** akan muncul dari PhishShield di layar dengan info:
     - 📡 *Tujuan:* `httpbin.org`
     - 📋 *Data:* 🔒 Password, 📧 Email, 🪪 NIK
   - Cobalah klik **🚫 Blokir Pengiriman**: Form **tidak akan dikirim**.
   - Coba lagi dan klik **✅ Izinkan Sekali**: Form akan terkirim ke `httpbin.org`.

##### 🧪 Tes 2: Fetch API (Pencegatan AJAX Background Request)
1. Klik tombol hijau **"Kirim via Fetch API (Password & Credit Card)"**.
2. **Hasil yang Diharapkan:**
   - Pop-up alert dari PhishShield akan muncul menanyakan izin transfer data ke `jsonplaceholder.typicode.com`.
   - Menampilkan deteksi 🔒 Password & 💳 Nomor Kartu.
   - Jika kamu klik **Blokir**, di layar akan muncul alert *"🚫 Request dibatal/diblokir oleh PhishShield"*.

---

#### 4. Cek Log Aktivitas (Di Background Extension)
Untuk memastikan data log tersimpan di `chrome.storage.local`:
1. Kembali ke `chrome://extensions/`.
2. Pada kartu ekstensi PhishShield, klik link **Service worker** (di samping tulisan *Inspect views*).
3. Buka tab **Console**, lalu ketik:
   ```javascript
   chrome.storage.local.get('activity_log', (data) => console.log(data.activity_log));
   ```
4. Kamu akan melihat riwayat event kapan data diblokir atau diizinkan lengkap dengan timestamp!
